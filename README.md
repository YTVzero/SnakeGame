# Змейка (Snake Game) — SFML 2.5

Реализация игры «Змейка» по техническому заданию (ГДД).

## Требования

- CMake ≥ 3.16
- C++17
- SFML 2.5+ (graphics + audio)

### Установка SFML (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install libsfml-dev
```

### Установка SFML (Windows / vcpkg)

```bash
vcpkg install sfml
```

## Сборка

```bash
mkdir build && cd build
cmake ..
cmake --build .
```

Бинарник появится в `build/`, папка `assets/` скопируется рядом автоматически.

## Управление

| Клавиша | Действие |
|---------|----------|
| **W / A / S / D** | Управление змейкой / навигация по меню |
| **Enter** | Выбор пункта меню |
| **B** | Назад / выход в меню (из паузы) |
| **P** | Пауза во время игры |
| **Backspace** | Удаление символа при вводе имени |

## Соответствие ТЗ

- ✅ Поле 25×19 клеток, стены по периметру
- ✅ 5 уровней сложности (скорость V + очки P)
- ✅ Задержка старта T = 1.5 с
- ✅ Рост змейки L = 1
- ✅ Таблица рекордов (X=5 в попапе, Y=10 на вкладке)
- ✅ Имя по умолчанию «XYZ»
- ✅ Меню: Начать игру / Сложность / Рекорды / Настройки / Выход
- ✅ Пауза, сохранение рекордов в `records.dat`
- ✅ Звуки (опционально — положите `.wav` в `assets/`)

Звуковые файлы (`button.wav`, `apple.wav`, `death.wav`) можно добавить в `assets/` — игра подхватит их автоматически.
